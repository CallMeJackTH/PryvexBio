# Pryvex Bio (Vercel + Supabase)
ค่าตั้งค่าทั้งหมด (รหัสแอดมิน, คีย์ Supabase) อยู่ในไฟล์เดียว: api/_config.js
1. Supabase > SQL Editor: รันไฟล์ supabase.sql หนึ่งครั้ง
2. อัปโฟลเดอร์นี้ขึ้น GitHub แบบ **Private** แล้ว Import เข้า Vercel (Framework: Other) หรือใช้ Vercel CLI: vercel --prod
3. กดที่รูปโปรไฟล์เพื่อเข้าแอดมิน (รหัสตาม ADMIN_PASSWORD ใน _config.js)
